# Nexus Main

A React.js-based web application that I worked on during my frontend development internship. As part of the internship, I cloned the existing project repository, contributed new features, enhanced the user interface, and assisted in deploying the application to Vercel.

## Internship Contribution

During my internship, I was responsible for implementing and integrating several frontend features, improving the application's functionality and user experience.

### Features Added

* Calendar Module

  * Added an interactive calendar for scheduling and managing events.

* Video Call Integration

  * Implemented the frontend interface for video calling functionality.

* Document Chamber

  * Developed a centralized document management section for viewing and organizing files.

* Payments Module

  * Designed and integrated payment-related user interfaces.

* Security Features

  * Implemented frontend security enhancements and improved user authentication-related interfaces.
